- 公開サイト: https://otonaworld-tomo.github.io/it-passport-study/
- 全118問
- 分野別成績、復習モード
- PWA・オフライン利用対応

端末間同期を有効にするには、[SETUP.md](SETUP.md)に従ってFirebaseを設定してください。
